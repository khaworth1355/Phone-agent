# Phone Agent - AI-Powered Call Handler

An AI agent that answers phone calls, transcribes conversations, and takes structured notes.

## Technology Stack
- Flask (Web Framework)
- Twilio (Telephony)
- Deepgram (Speech-to-Text)
- Anthropic Claude (AI Agent)
- ElevenLabs (Text-to-Speech)
- SQLite (Database)

## Setup Instructions
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in credentials
4. Run: `python app.py`
